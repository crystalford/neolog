Neural Engine Optimization is my name for making something new enough that an AI search engine wants to cite it — as opposed to the usual goal, which is just getting found faster. The word "Neural" may change.
2 Sep 2026a term · status: draft · 7 usesits page →
There are five acronyms for getting cited by AI — SEO, AEO, GEO, LLMO, AIO — and all of them are about being retrieved. None is about being worth retrieving. I noticed they all end in EO, then noticed this site's name starts with NEO, and named the missing idea on the spot. I'm not sure "Neural" is the right N; it might be "Novel." The idea is settled and the word isn't. The whole afternoon, written up.

Don't give a coding agent your design files and expect it to build the design. Give it a written spec so clear it can't be misread — and have the design tool write that spec.
3 Sep 2026a position · changed once · status: stated · how sure: likelyits page →
My first version of this blamed the coding agent. This version blames the handoff — what I gave it wasn't clear enough to follow. Two real incidents are behind it: the agent using colour values from a stale file (the token drift), and the agent building a card style I'd told it I hated (the border card).

About 84% of the sources AI engines cite are other people's pages talking about you, not your own — so a personal site like this one has to get mentioned elsewhere, not just exist.
2 Sep 2026a finding · built on someone else's research
The 84% figure comes from a study by Muck Rack, a media-research company. The conclusion I drew from it is mine: you can build a perfectly structured site and still be invisible to AI, because it's looking at what other people say about you. What I'm doing about that has its own page.
